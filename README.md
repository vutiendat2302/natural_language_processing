## 📚 Syllabus & Progress

| Week | Theory Topics | Practical / Lab | Status |
| :---: | :--- | :--- | :---: |
| **01** | **Introduction to NLP**; Sparse & Dense Vector Representations; Count Vector Normalization; TF-IDF; Document Processing Pipeline; Demo on the 30K-Document Corpus | [**Lab 01 – From Text Processing to Search**](./practice/lab01/) | 🟢 Completed |
| **02** | **N-gram Language Models**; Maximum Likelihood Estimation (MLE); Laplace Smoothing; Perplexity Evaluation; Next-Word Prediction & Sentence Ranking | [**Lab 02 – Language Models**](./practice/lab02/) | 🟢 Completed |
| **03** | **Word Representations & Embeddings**; Distributional Hypothesis; Co-occurrence Matrix & Cosine Similarity; Word2Vec (CBOW & Skip-gram); Hyperparameter Tuning (Window Size & Dimension); Word Analogy & Semantic Search | [**Lab 03 – Word Representations and Embeddings**](./practice/lab03/) | 🟢 Completed |
| **04** | **Text Classification**; Supervised Machine Learning Pipeline; Feature Extraction (TF-IDF vs. Average Word2Vec); Linear Classifiers (Logistic Regression, Linear SVM); Evaluation Metrics (Precision, Recall, F1, Confusion Matrix); Class Imbalance & Data Leakage; Model Interpretability | [**Lab 04 – Text Classification**](./practice/lab04/) | 🟢 Completed |
| **05** | **Sequence Modeling & Recurrent Neural Networks**; Simple RNN, LSTM, and GRU; Hidden State Progression & Vanishing Gradient; Backpropagation Through Time (BPTT); Sequence Classification on IMDb | [**Lab 05 – Sequence Modeling**](./practice/lab05/) | 🟢 Completed |
| **06** | **Attention Mechanism**; From Recurrent State to Context-Aware Representation; Query, Key, and Value; Dot-Product vs. Scaled Dot-Product Attention; Softmax Normalization & Temperature Scaling; Self-Attention; $\mathcal{O}(T^2)$ Computational Complexity | [**Lab 06 – Attention Mechanism**](./practice/lab06/) | 🟢 Completed |
| **07** | **Transformer Architecture**; From Attention to Transformer; Multi-Head Attention & Subspace Projections; Sinusoidal Positional Encoding; Position-wise Feed-Forward Network (FFN); Residual Connection & Layer Normalization (Add & Norm); Transformer Encoder Block | [**Lab 07 – Transformer Architecture**](./practice/lab07/) | 🟢 Completed |
